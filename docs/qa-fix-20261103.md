# 中文問答誤拒答修正

## 現象與診斷

現場回報斑點與細胞的概念題收到通用「無法回答」。正式庫只保存最終回答，沒有原始模型生成內容，因此不能還原原次生成；隔離重現找到兩種可造成同樣結果的原因：

- 中文提示的 `[來源ID]` 被誤解為 `[來源ID: S06]`，不符既有引用ID檢查。
- UI加入的 `[Poster section: ...]` 位置前綴進入檢索，並讓短追問長度判斷失效；取回的Clue參數/細胞耦合內容缺少基礎色素背景。模型主動延伸未被問的融合必要條件，也會被研究範圍檢查擋下。

只有服務health ready不能證明任意題目可回答。

## 修正範圍

- 引用明確使用本輪實際ID（如 `[S06]`），禁止在括號內加「來源ID」或冒號。
- 中文回答聚焦實際問題，一段一至兩句，避免因海報區塊名稱而延伸整個Clue。
- 檢索先移除位置前綴；短追問可正常使用最近使用者問題。斑點/斑塊與細胞的概念題加入query-only的「花青素、色素分布」詞彙，不加入答案或指定來源IDs，且保持embedding長度上限。
- 不變更語料、向量索引、模型、英文段落選擇、來源/數值/研究範圍檢查或SQLite schema。
