# 海報導覽網頁試作計畫

此文件保留最初試作階段的授權與計畫範圍；後續新增的References／Supplementary與實際驗證狀態，見[網頁試作紀錄](poster-web-preview.md)。原六段完整導覽仍獨立保留。下列「不提交、合併或推送」是當時階段的限制，不代表後續發布授權或發布結果。

本輪依使用者「先用網頁試試看，注意手機尺寸和解析度」授權，在既有 `feat/bilingual-voice-guide` worktree 新增獨立 `/tour-preview/`。不替換首頁，不修改 backend、共用 speech controller 或既有資料，不提交、合併或推送；既有服務與實際 API 驗收由原目標對話承接。

1. 由原海報 PDF 的完整 `regions` 直接 clip 輸出 lossless WebP；總覽 800/1600px、六區 800/1600/2400px，以實際像素尺寸建立 manifest，記錄來源 SHA。Discussion 合併 conclusions 的邊界需核對。像素增加保留 PDF 字型和向量品質，不能增加內嵌科學圖原有細節。
2. 延續已確認總覽 → 完整區塊 → 返回的設計。原海報保持英文；English 預設、繁中切換。手機自然堆疊，桌面圖文並排；正文 18px、A+ 20/22px，44px 觸控，允許瀏覽器縮放。產品辨識沿用海報深藍與少量紫色，白底、中性色閱讀，不另抽選設計系統。
3. 導覽文字預設可讀，來源 ID 可查。沿用 `/speech.js` 和既有 speech API，六段完整導覽逐段播放且不自動放大區塊；切語言、手動換區或離頁會停止舊音訊。2–3 分鐘僅是目標，未量測不宣稱達標。
4. 問答沿用 `/api/chat`：含固定區塊背景的問題最多 600 字元，最多四則、每則 1000 字元 history。pending 防重、清除會 abort 並忽略舊回覆，無自動重試；來源以安全文字與原文連結呈現。不儲存對話，僅儲存語言偏好。
5. 聚焦驗證 sequence 停止／結束競態、URL、語言、問題長度、history 與清除；使用既有 Node/Playwright，不新增依賴或 server。檢查 320/360/390/430px、DPR 1/2/3 與桌面；實際聲音、人類聆聽及外部手機可達性分開回報。

畫面回答的核心問題是「這張海報在說什麼、我現在聽到／讀到哪一區？」；完整海報與可讀 HTML 文字是主要內容，播放控制位於第一屏，問答是次要操作。
