# 雙語語音導覽：設計與實作計畫

日期：2026-10-29。起點：`3900ee1`。使用者要求英文／中文選擇、預設英文，並選定「播放導覽與回答：可播放、暫停、停止，搭配點選問題繼續探索」。

## 目標與做法

沿用既有 FastAPI、原生 HTML/CSS/JavaScript、CPU hybrid RAG 與 Qwen，不改研究來源或模型部署。第一次開啟用 English；頂部提供 English / 繁體中文切換，僅保存語言偏好，不保存對話。介面、介紹、Clue 1–3、建議問題、錯誤提示及新回答跟隨所選語言。已有問答保留原語言並帶自己的朗讀語言；不冒稱切換已翻譯歷史。進行中的請求保留送出時語言。

最終語音方案：實測瀏覽器沒有英文 OS voice，因此以同一 FastAPI 內的 Kokoro／sherpa-onnx CPU 雙語合成取代初版 SpeechSynthesis。靜態導覽預錄快取，動態回答只在記憶體短暫快取；瀏覽器 HTMLAudio 提供播放／暫停／停止。沒有新增另一個服務、OS 語音、雲端 TTS、GPU、麥克風或語音辨識。首次非同步播放遭瀏覽器阻擋時保留已備妥音檔，由下一次使用者 Play 手勢直接播放。

播放入口在介紹、目前線索、每個可回答的模型訊息旁；共用可見的播放／暫停或繼續／停止狀態。只播一段；新播放取代舊播放，切換語言／線索、清除對話、離頁皆停止。朗讀跳過來源 ID，但畫面仍保留完整引用。下一條／上一條線索及各線索的提問入口形成可點選探索，不新增沒有研究依據的模擬控制。

## API 與資料

- `POST /api/chat` 新增 `language: "en" | "zh-TW"`，預設 `en`；在同一 system prompt 明確指定回答語言，來源與 history 不得覆蓋。狀態訊息與 confidence 說明對應語言。
- `/api/guide?language=en|zh-TW` 提供對應文案，預設 en。既有 `data/guide.json` 保留中文，英文另存 `data/guide.en.json`，研究來源 ID 不變。
- 來源視窗的控制與 metadata 標籤切換語言；英文主要呈現原始英文摘錄，中文校對摘要可明確標為中文摘要，不把它偽裝為英文翻譯。必要英文來源標題由固定在地化資料提供。原始 PDF 不翻譯、不改動。
- 既有證據、索引及來源 SHA 不變；若有理由要改研究摘要或索引，先回 root 確認。
- 既有單一生成、最多兩筆等待、拒答、引用／數值檢查、無自動重送都保留。針對英文補上現有科學過度宣稱的回歸保護；拒答限制仍誠實揭露。

## 驗收與界線

手機寬度看得見兩個語言選項及播放狀態，切換無橫向溢位；選中文後可切回英文。介紹、線索、回答都可手動朗讀及停止，沒有麥克風要求。音訊尚未佈建或合成失敗時文字問答仍可用。非同步舊音訊事件不能恢復被停止的播放。模型以兩種語言答同一代表題、精確參數、追問與未知題，保留引用和模擬限制。

實際播放器事件不等於人工聽感驗收；基因名稱與公式的發音品質、實機手機聲音另列待驗收。固定模型、授權、效能與版本取捨見[本機雙語音訊](local-speech.md)。

## 工作與部署範圍

在獨立 worktree `feat/bilingual-voice-guide` 開發；原 main 與 8000/ngrok 繼續服務。根據已授權試用流程，root 完成核對後更新本專案試用 app；不重啟模型、不影響 NeuroAI。新版本尚未獲另一次 commit／merge／push 授權，先保留可核對變更。

## 實測後的最終調整

4B 模型英文自由轉述反覆漏掉條件或改錯圖號，未降低原驗收門檻。最終新增綁定原語料 hash 的 21 筆已核對英文摘要，英文 RAG 由模型選完整段落、後端原字呈現並附當輪引用，禁止任意新增文字。繁中恢復原版完整生成輸入。工程、真實模型、公開入口與語音限制以 `docs/bilingual-validation.md` 的最終結果為準。
